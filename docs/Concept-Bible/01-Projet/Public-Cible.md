# Public cible

> **Statut :** Validé

Le jeu est destiné aux **enfants à partir de 7 ans**.

La conception doit privilégier :

- des objectifs faciles à comprendre ;
- un chemin unique par niveau ;
- une difficulté progressive ;
- des effets lisibles ;
- l'absence de violence graphique ;
- des combats de boss basés sur l'observation et l'apprentissage.
