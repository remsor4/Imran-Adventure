# Slimes

> **Statut :** Validé

Les slimes se déplacent en bondissant. Leur apparence s'adapte à chaque environnement :

- slime végétal dans la Forêt enchantée ;
- slime rocheux ou cristallin dans la Grotte mystérieuse ;
- slime glacé au Lac gelé ;
- slime de sable dans le Désert oublié ;
- slime de lave au Volcan ;
- slime sombre dans le Château de Tata Lisa.
