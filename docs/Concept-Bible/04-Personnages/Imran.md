# Imran

> **Statut :** Validé

| Élément | Description |
|---|---|
| Âge | 10 ans |
| Rôle | Héros principal |
| Origine | Village des Blés |
| Arme | Shadow Sword |
| Défense | Bouclier de lumière |

Imran est courageux, optimiste, généreux et déterminé. Son caractère s'inspire du type de héros chaleureux et positif représenté par Sora dans *Kingdom Hearts*, sans reprendre son apparence ni son univers.

Il part seul sauver Aliyah pendant l'absence de ses parents.
