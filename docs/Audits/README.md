# Audits

Ce dossier contient les revues critiques transversales de la documentation d'Imran Adventure.

Une revue analyse l'etat reel du Concept Game, du GDD et du TDD a un instant donne : ce qui est ecrit, ce qui manque, les incoherences, les risques et les priorites de correction. Une revue n'est pas une source de verite sur les regles du jeu : elle n'ajoute et ne remplace aucune decision de gameplay. Les corrections qu'elle propose doivent etre reportees dans le document concerne (Concept Game, GDD ou TDD) pour devenir effectives.
