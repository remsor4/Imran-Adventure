# 10 - Direction sonore

Ce dossier definit l'identite sonore de **Imran Adventure**. Il sert de reference pour la musique, les ambiances, les effets de gameplay et les voix.

La direction sonore repose sur quatre priorites :

- une aventure fantasy melodique et chaleureuse ;
- une identite propre a chaque environnement ;
- des sons de gameplay immediatement reconnaissables ;
- un mixage clair et confortable pour les enfants a partir de 7 ans.

## Hierarchie sonore

Quand plusieurs sons sont joues en meme temps, la priorite est :

1. danger immediat et attaque ennemie ;
2. action, degat et protection d'Imran ;
3. interaction, recompense et interface ;
4. voix narrative ;
5. musique ;
6. ambiance de l'environnement.

La musique et l'ambiance doivent soutenir l'action sans masquer les informations utiles au joueur.

## Reglages proposes

Le menu Audio doit proposer des controles separes pour :

- volume general ;
- musique ;
- effets sonores ;
- ambiances ;
- voix.

Chaque categorie peut etre diminuee ou coupee. Une information de gameplay conserve toujours un equivalent visuel.
