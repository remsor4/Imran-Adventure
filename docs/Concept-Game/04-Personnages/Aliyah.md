# Aliyah

> **Statut :** Validé

| Élément | Description |
|---|---|
| Âge | 8 ans |
| Rôle | Petite sœur d'Imran |
| Situation | Prisonnière dans le donjon |

Aliyah est douce, courageuse, gentille et très proche de son frère. Tata Lisa l'enlève pour lui voler sa beauté.

Elle reste prisonniere pendant que Tata Lisa prepare un rituel complexe qui demande plusieurs jours. Imran doit la liberer avant que le sort ne soit acheve.
