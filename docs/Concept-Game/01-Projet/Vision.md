# Vision

> **Statut :** Validé

Créer un jeu de plateforme 2D familial, accessible dès 7 ans, reposant sur :

- une progression claire et entièrement linéaire ;
- des commandes simples et précises ;
- des combats faciles à comprendre ;
- un boss à la fin de chaque niveau ;
- le Dash et le Double saut disponibles des le debut et enseignes dans le niveau 0 ;
- une direction artistique en dessin animé ;
- une aventure épique centrée sur la famille.
