# 09 - Direction artistique

Ce dossier definit l'identite visuelle de **Imran Adventure**. Il sert de reference commune pour les personnages, les decors, l'interface, les animations et les effets visuels.

La direction artistique repose sur quatre priorites :

- un style cartoon 2D chaleureux et expressif ;
- une lecture immediate de l'action et des dangers ;
- des environnements clairement differencies ;
- une ambiance fantasy adaptee aux enfants a partir de 7 ans.

## Regle de coherence

Chaque nouveau visuel doit respecter le style graphique, la palette de sa zone et les regles de lisibilite definies dans ce dossier. Les details propres aux personnages, aux ennemis et aux boss restent decrits dans leurs documents respectifs.
