# Déroulement

> **Statut :** Validé

Apres la cinematique au Village des Bles, le joueur prend le controle d'Imran au debut du premier niveau. Imran traverse successivement les six niveaux principaux :

1. la Forêt enchantée ;
2. la Grotte mystérieuse ;
3. le Lac gelé ;
4. le Désert oublié ;
5. le Volcan ;
6. le Château de Tata Lisa.

Chaque niveau se termine par un golem qui protège un coffre. Imran doit vaincre le gardien puis ouvrir lui-même le coffre pour récupérer la clé.

Il débloque le Dash après le deuxième golem et le Double saut après le quatrième golem.

Le donjon apparait uniquement dans la scene finale apres le combat contre Tata Lisa. Il ne constitue pas un septieme niveau.
