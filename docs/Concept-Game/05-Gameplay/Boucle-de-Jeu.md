# Boucle de jeu

> **Statut :** Valide

## Niveau 0

Avancer sur un chemin unique, lire une pancarte de tutoriel, pratiquer la commande dans une courte situation de plateforme ou de combat, puis atteindre la pancarte suivante jusqu'a la sortie du Village des Bles.

Le niveau 0 se termine sans golem, sans coffre et sans cle.

## Six niveaux principaux

Avancer sur un chemin unique, franchir les plateformes, combattre les ennemis, activer la pancarte de controle, atteindre le golem, le vaincre, ouvrir le coffre, recuperer la cle et passer au niveau suivant.
