# GDD - Progression et equilibrage

Organiser une montee en difficulte progressive, lisible et juste pour un public a partir de 7 ans.

## Principes deja valides

- Le jeu possede une seule difficulte.
- Toutes les capacites d'Imran sont disponibles des le niveau 0.
- La difficulte augmente par les plateformes, les combinaisons d'ennemis et les boss.
- Les Squelettes sont remplaces par les Zombies dans les deux derniers niveaux.
- La courbe suit des vagues douces avec un pic au boss et une respiration au debut du niveau suivant.

## Criteres de validation de l'etape

L'etape 10 est prete a etre validee si :

- la pression augmente progressivement du niveau 0 a Tata Lisa ;
- chaque niveau principal possede une introduction, une montee, une respiration et un boss ;
- le Dash et le Double saut progressent par couches sans nouveau deblocage ;
- chaque sequence possede une duree cible ;
- le nombre et la repartition des dangers sont mesurables ;
- les valeurs modifiables et verrouillees sont distinguees ;
- le profil de joueur novice est defini ;
- les objectifs d'echec et les mesures de test sont observables ;
- Rems et Codex doivent valider chaque section testee.
