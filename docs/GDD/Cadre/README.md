# Cadre du GDD

> **Statut :** Valide

## Objectif

Le cadre definit le role du Game Design Document, les informations qu'il contient et la methode utilisee pour le maintenir coherent.

Le GDD doit permettre de comprendre exactement :

- ce que le joueur peut faire ;
- les conditions de chaque action ;
- les valeurs utilisees ;
- le comportement des personnages, ennemis, boss et systemes ;
- le deroulement des niveaux ;
- les retours visuels et sonores attendus ;
- les criteres permettant de verifier qu'une fonction est correcte.

Le GDD explique le fonctionnement du jeu. Il ne decrit pas la structure du code Godot.
